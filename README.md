# 星海衝突

皇室戰爭的節奏，配上星海爭霸的經濟：直式手機畫面的即時戰略小遊戲。可以單機對電腦，也可以在本機架 server 跟真人即時對戰。

網頁版：<https://agan0617.github.io/StarClash/>（純 HTML＋Canvas，沒有相依套件，手機瀏覽器直接玩，可加到主畫面離線玩）

## 玩法

- **目標**：4 分鐘內拆掉對方的主堡，或拆掉比對方多的塔。平手就進入 1 分鐘驟死戰，先拆一座塔的獲勝；再平手比剩餘塔血。最後 90 秒與驟死戰，礦和瓦斯收入加倍
- **戰場**：直式，玩家在下、電腦在上，兩條路各有一座前哨塔守著，主堡在最後。河把戰場分成兩半，只能在自家半場放兵
- **出兵**（皇室戰爭）：按住下方兵種卡拖到自家半場，放手的位置兵立刻出現、沿那條路往上推，遇到敵人就打，塔拆了就往主堡走。拖的時候會顯示半透明預覽與射程圈，放不下（位置、資源、人口、科技不夠）會變紅；拖回面板放手就取消。只點一下卡片不拖，兵會放在自家半場的隨機位置
- **種族**：開局前選自己的種族（人族、蟲族、神族），對手可指定或隨機。三族的建設角色一樣，名字和兵種不同（見下表）
- **經濟**（星海爭霸）：礦工自動挖礦，前 8 隻每隻 +1.5 礦/秒、第 9～16 隻 +0.75（礦區飽和）。瓦斯要蓋瓦斯建築（每座 +2/秒，最多 2 座）。每個單位佔人口，人口滿了要蓋補給（+8，上限 50）
- **科技**：一階 → 二階 → 三階建築，蓋好才解鎖對應兵種；強化（升級）全軍攻擊 +10%，可升 3 級。建設不佔戰場，按一下就開始蓋，可以同時蓋好幾樣；礦工在主堡一次訓練一隻、可排隊
- **畫面右上**看得到電腦的礦、瓦斯、礦工與人口——偵查要素的簡化版，看對手是在爆經濟還是在存兵

### 種族與建設

三族、兵種與建設的名字和美術都是本作原創（0.8.0 起；0.10.0 三族都重畫並改名）；括號裡是程式裡的 id（`js/data.js`），重播與連線存的是 id，改名不影響。

| 角色 | 人族（`terran`） | 蟲族（`zerg`） | 神族（`protoss`） |
|---|---|---|---|
| 礦工 | 採礦機 | 採集體 | 符文工匠 |
| 補給（人口 +8） | 電池艙 | 共生囊 | 能量方尖碑 |
| 瓦斯 | 氣體泵 | 吸氣巢 | 凝氣塔 |
| 一階 | 機兵廠 | 幼體巢 | 召喚陣 |
| 二階 | 機甲廠 | 甲殼巢 | 秘械工坊 |
| 三階 | 航空塢 | 飛翼巢 | 浮空港 |
| 升級 | 武裝升級 | 進化腺 | 符文強化 |

- **人族**（可愛但正經的機器人與機甲：護目鏡發光大眼、粉彩鋼藍裝甲＋柔橘）：兵種均衡、射程長，砲擊機甲能站在塔外轟
- **蟲族**（可愛外星生物：觸角、大單眼或多隻眼、發光斑點、半透明身體；萊姆綠＋深青綠，發光斑點黃綠與螢光橘）：便宜、量多、跑得快；所有單位每秒回 1.5 血（殼甲獸再多 4）
- **神族**（神秘力量帶機械：符文光紋、漂浮能量核心、光環與靈光粒子，珍珠白金屬裝甲＋金色符文與黃銅齒輪，能量核心是偏綠的青色）：貴但耐打；每個單位多一條護盾，傷害先扣護盾，3 秒沒挨打就每秒回 4

### 電腦對手

| 等級 | 收入 | 反應 | 剋制 |
|---|---|---|---|
| 簡單 | 70% | 1.5 秒看一次 | 不會針對你的兵種 |
| 普通 | 100% | 0.8 秒 | 會出剋制兵 |
| 困難 | 125% | 0.5 秒 | 會出剋制兵、礦工更多 |

電腦照星海的開局思路蓋經濟，你的兵進到它半場就在那條路放兵守、塔血剩一半補砲塔；礦存到一波的預算（隨時間變大）就全放在你較弱的那條路推過來，收入加倍那段與驟死戰不太存礦、有就推。

### 連線對戰（真人）

1. 在一台電腦上開 server（要裝 Node.js，沒有其他相依套件）：

   ```
   node server/server.js
   ```

   它會印出網址：本機是 `http://localhost:8787/`，區網是 `http://<這台電腦的 IP>:8787/`。要換 port 就在後面加數字（`node server/server.js 9000`）
2. 兩個人都用 **server 印出的網址**開遊戲（手機和電腦都行，同一個 Wi-Fi），選好自己的種族按「連線對戰」，先到的等對手、兩個人都按了就配對開打
3. 兩邊都看到自己在下方；開打前倒數 3 秒，連線對戰不能暫停

- 斷線：重新整理（F5）或網路斷掉會自動連回原本那一場；斷線 3 秒起由電腦代打，15 秒沒連回判中離（對手獲勝）
- GitHub Pages 上的網頁版沒有 server，只能對電腦
- 手機連不上：第一次開 server 時 Windows 防火牆會問要不要讓 Node.js 通過，要允許「私人網路」

### 重播

每一場（對電腦與連線對戰）打完都會自動存成重播，留最近 20 場在這台裝置。結算畫面按「看重播」，或主選單按「重播」挑一場。播放時下方有暫停、速度（×1／×2／×4／×8）、進度條（拖曳可跳到任一時間）與離開。重播是從自己的視角看；改版後數值變了，舊版錄的重播會和當時不一樣。

### 鍵盤（電腦上玩）

出兵一樣用滑鼠拖卡片；Q/W/E/R/T/Y/U 建設（照面板由左到右：礦工、補給、瓦斯、一階、二階、三階、升級）、P 暫停（只限對電腦）。

## 美術

0.8.0 起換成原創的 **Q 版可愛科幻風**：粗深色外框、圓潤造型、大眼睛或發光的眼睛、平塗＋一層陰影＋一點高光，同族同配色。0.10.0 三族都重畫：人族是可愛但正經的機器人／機甲（護目鏡發光大眼），蟲族是可愛外星生物（觸角、大單眼、發光斑點、半透明身體），神族是符文能量配精緻機械（漂浮能量核心、光環、黃銅齒輪）；都是 Q 版、圓亮大眼、沒有尖牙利刺。三族各有一眼分得出的主色（0.10.1）：人族鋼藍＋柔橘、蟲族萊姆綠＋深青綠、神族珍珠白＋金；神族能量用偏綠的青色，避開我方底圈的藍；地面小草叢改淡紫，不跟綠色的蟲族混在一起。

- **圖檔**：全部是 SVG，放在 [assets/svg/](assets/svg/)，一個檔一張圖，可以直接用 Inkscape／Figma 開來改（存回同檔名即可）
  - 21 個兵種：檔名就是兵種 id（`marine.svg`、`zergling.svg`…），viewBox 64×64，角色預設**朝右**
  - 塔：`outpost_<種族>.svg`、`main_<種族>.svg`（viewBox 96×96），三族各一組
  - 建設圖示：`b_<角色>.svg`（48×48，三族共用）；UI 圖示：`i_mineral`、`i_gas`、`i_worker`、`i_supply`、`i_crown`、`i_lock`（32×32）
- **敵我顏色**：SVG 裡的隊伍色寫成 `#4da3ff`（主色）、`#a9dcff`（亮）、`#1f4a80`（暗），載入時藍隊照原樣、紅隊自動換成紅色。要讓某個部位跟著隊伍變色就用這三個色碼，其他顏色不會被換
- **戰場上怎麼分**：單位腳下有隊伍色的底圈（藍＝我方、紅＝敵方），空中單位浮在半空、底圈是虛線，影子留在地上
- **怎麼畫到畫面上**：`js/render.js` 載入時把每張 SVG 轉成藍、紅兩份圖，第一次用到時畫進離屏畫布快取，之後每格只 `drawImage`；角色只左右翻面、不旋轉。SVG 還沒載好或載不到時，退回舊版的 Canvas 程式畫法，不會黑畫面
- **地形、面板、按鈕、特效**仍是程式畫（`js/render.js`、`style.css`），同一套圓角粗框的風格
- 新增或改名圖檔：`js/render.js` 的 `ART_FILES`／`ART_SIZE` 和 `sw.js` 的離線快取清單都要跟著改，並把兩邊的 `VERSION` 加一

## 開發

- 全部數值在 [js/data.js](js/data.js)，改平衡只改這個檔；規則與為什麼這樣定見 [docs/DESIGN.md](docs/DESIGN.md)
- `node tools/simulate.js 30 normal hard zerg protoss`：無頭跑電腦對電腦 30 場，看勝率、時長、出兵分布；種族寫 `all` 會跑三族對戰勝率表（正反各半）。環境變數 `PATCH` 可以不改檔試數值
- `node tools/duel.js 1200 [種族]`：兵種對決表，兩種兵花同樣的錢對打
- `node tools/strategy.js 60 normal`：策略測試，電腦當玩家只出一階兵／不出空軍／全部混出，各自對同等級電腦的勝率
- `node server/server.js [port]`：連線對戰 server，同一個 port 也提供網頁；同步做法見 [docs/DESIGN.md](docs/DESIGN.md)〈連線對戰〉
- `python tools/make_icons.py`：重產 PWA 圖示
- 改版：`js/data.js` 的 `VERSION`、`sw.js` 的 `VERSION` 都加一，不然舊快取不更新
